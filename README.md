# Инструмент трансляции конфигурационного языка (Вариант 16)

## 1. Общее описание
Данный инструмент командной строки преобразует текст на учебном конфигурационном языке в формат YAML. 
Входной текст принимается из стандартного потока ввода (stdin). Выходной текст записывается в файл, путь к которому передается через аргумент командной строки `-o` или `--output`.
При возникновении синтаксических ошибок или ошибок вычислений инструмент выводит сообщение в `stderr` и завершается с кодом `1`.

## 2. Описание всех функций и настроек
*   `-o`, `--output` — обязательный аргумент, задающий путь к выходному файлу `.yaml`.
*   Поддерживаемые конструкции языка:
    *   Многострочные комментарии: `|# ... #|`
    *   Числа с плавающей точкой: `[+-]?\d+\.\d+`
    *   Массивы: `'( значение значение значение ... )`
    *   Имена (идентификаторы): `[_a-zA-Z]+`
    *   Объявление константы: `var имя = значение`
    *   Вычисления на этапе трансляции: префиксная форма `.{+ имя 1.0}.`, `.{sqrt 4.0}.`
    *   Операции: `+` (сложение), `sqrt` (квадратный корень).
